# REFRAME

**REFRAME: A Test Suite for the Knowledge–Deployment Gap in LLMs**

Official repository for the REFRAME benchmark, accepted to **EMNLP 2026 Main Conference**.

**Paper:** https://openreview.net/forum?id=lTU1B7Jlsn

REFRAME contains 150 paired deployment and knowledge probes for evaluating whether LLMs can recognize and break invalid answer frames.

## Files

- `data/reframe.jsonl` — REFRAME benchmark dataset

For the full methodology, prompting setup, scoring procedure, and experimental results, please see the paper.
